# Lab 3

**Aim:** Write a C program using open(), read(), write(), and close() system calls for copying the content of one file to another file. The program must be interactive and must take the following inputs from the user as `<name of existing file>` and `<name of new file>`. Ensure proper error handling and code indentation.

**Source:** [`file_copy.c`](file_copy.c)

```bash
gcc file_copy.c -o file_copy
./file_copy
```

## Output

```
$ ./file_copy
<name of existing file> student.dat
<name of new file> student_copy.dat
File copied successfully!
```
